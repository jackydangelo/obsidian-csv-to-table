A simple Obsidian plugin that converts selected csv like text into Markdown tables.

## Usage
- Select text containing a text separated by ","
- Open the command palette (Ctrl/Cmd + P)
- Run command "CSV to table: Convert CSV selection to Markdown table"

## Example
Given this selection:

```text
Fruit,color
apple,red
banana,yellow
```

Convert into a table:
| Fruit | Color |
| -------- | -------- |
| apple | red |
| banana | yellow |
